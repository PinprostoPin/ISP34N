git clone
Скачать копию чужого репозитория (из интернета) к себе на компьютер.

git status
Посмотреть, что сейчас происходит в папке: какие файлы изменены, какие добавлены, а какие вообще Git не видит.

git add
Сказать Git'у: «Этот файл я хочу сохранить в следующей версии». Как добавление в корзину, но для коммита.

git commit
Сделать «снимок» всех добавленных файлов и записать его в историю. Добавляешь к нему пояснение (-m "что сделал").

git push
Отправить свои сохранённые коммиты на сервер (например, на GitHub), чтобы другие их увидели.

git pull
Наоборот, забрать с сервера свежие изменения, которые сделали другие, и подтянуть их к себе.

git log
Показать всю историю коммитов: кто, когда и что писал.

git branch
Посмотреть список всех веток (отдельных линий разработки) или создать новую.

git checkout
Переключиться на другую ветку или на конкретный старый коммит.

git merge
Взять изменения из одной ветки и влить их в текущую (склеить две линии разработки).
