# 1. Что такое Git и для чего он используется?
Запоминает все изменения

# 2. В чём разница между централизованными и распределёнными системами контроля версий?
Централизованные - все файлы хранятся на одном главном сервере и нужно быть онлайн, чтобы посмотреть историю
Распределённые - у каждого разработчика на компьютере лежит полная копия всего проекта со всей историей, можно работать без интернета, коммитить, смотреть изменения

# 3. Что такое репозиторий в Git?
Репозиторий - это просто папка, в которой Git хранит все твои файлы и всю историю их изменений.
